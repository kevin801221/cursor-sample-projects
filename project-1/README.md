# 第 0 課 — 環境準備

> 開課前先把環境弄到**全綠**：工具裝好、帳號辦好、三個核心概念先聽過一遍。
> 之後 14 個專案（project-2 ~ project-14）當天就能直接開跑，不會把時間燒在「我這邊裝不起來」。

## 這一課做什麼

| | |
|---|---|
| **最終成果** | 你的電腦通過本課的健康檢查清單，且必要帳號全部申請完成 |
| **預估時間** | 60–90 分鐘（下載等待時間長，建議提早開始） |
| **前置需求** | 一台 macOS 或 Windows 電腦、可上網 |

## 為什麼要有第 0 課

Docker 映像好幾 GB、Node 套件上千個、帳號申請要收驗證信——這些事**等到要用時才做一定卡住**。
第 0 課的哲學：**把必然會發生的失敗前移**。

## 內容

完整清單與逐步指引見 **[walkthrough.md](./walkthrough.md)**：

1. **裝機五件套**：Cursor、Node 20+、Docker Desktop、uv、git（各附一行驗證指令）
2. **Docker 預載服務解說**：見 **[docker-services.md](./docker-services.md)**（白話解說 Supabase 與 Neo4j 容器用途）
3. **帳號申請總表**：14 個專案會用到的所有帳號，全部免費方案即可，標注哪幾課會用到
4. **三個核心概念先修**：Agent、`.cursor/rules`、MCP——之後每一課都會碰到
5. **健康檢查**：一段可以直接跑的驗證指令，全綠才算完成
6. **防翻車救援總手冊**：見 **[TROUBLESHOOTING-MASTER.md](../TROUBLESHOOTING-MASTER.md)**（全課程 14 專案常見卡點與 30 秒急救法）
